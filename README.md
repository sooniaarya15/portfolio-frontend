# Portfolio Frontend

The public-facing portfolio website, built with Next.js and Tailwind CSS.
All content is pulled live from a custom-built CMS backend, so updating
the site is as simple as editing content in the admin panel.

## Pages
- Home (intro, featured projects, skills)
- About
- Projects
- Skills (grouped by category, with proficiency bars)
- Experience (timeline)
- Blog (published posts only)
- Contact (form that saves to the database and emails the site owner)

## Tech Stack
Next.js 14, React 18, Tailwind CSS
